# Produtos API – ASP.NET Core (.NET)

API REST para **cadastro e gerenciamento de produtos**, desenvolvida em **ASP.NET Core (.NET)** com foco em **boas práticas de backend**, simplicidade e extensibilidade.  
O projeto utiliza **Minimal APIs**, documentação automática com **Swagger/OpenAPI** e estrutura preparada para evolução futura.

---

## 🚀 Tecnologias Utilizadas

- **.NET 8 / .NET 9**
- **ASP.NET Core**
- **Minimal APIs**
- **Swagger / OpenAPI**
- **C#**
- **Git & GitHub**

---

## 📌 Funcionalidades

- Listar todos os produtos
- Buscar produto por ID
- Cadastrar novo produto
- Atualizar produto existente

---

## ▶️ Como Executar o Projeto

### Pré-requisitos
- **.NET SDK** instalado
- **Git**

### Passos

```bash
git clone https://github.com/joaobosco-devbr/produtos-api-dotnet.git
cd produtos-api-dotnet
dotnet restore
dotnet run

🌐 Acesso à API

Após iniciar a aplicação, a API estará disponível em:

HTTP: http://localhost:5284

HTTPS: https://localhost:7046

A documentação interativa pode ser acessada via Swagger UI no ambiente de desenvolvimento.
